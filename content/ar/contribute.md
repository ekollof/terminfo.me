## كيفية المساهمة بإدخال terminfo جديد

نرحب بملفات مصدر terminfo عالية الجودة للأجهزة الطرفية المفقودة من قاعدة بيانات ncurses في النظام أو التي تحتوي على تعريفات أفضل أو أكثر اكتمالاً.

**ملاحظة حول اللغة:** يُرجى كتابة وصف المشاكل (issues) وطلبات السحب (pull requests) والتعليقات باللغة الإنجليزية. هذا يساعد المشرفين على مراجعة المساهمات بكفاءة.

### البداية السريعة (موصى بها)

أسهل طريقة للمساهمة هي **فتح issue أولاً**:

→ **[إرسال terminfo جديد عبر GitHub Issue](https://github.com/ekollof/terminfo.me/issues/new?template=new-terminfo.yml)**

هذا يمنحنا فرصة لمراجعة الإدخال وتقديم ملاحظات قبل فتح طلب سحب.

---

### العملية اليدوية (للمساهمين ذوي الخبرة)

إذا كنت تفضل فتح طلب سحب مباشرة، اتبع هذه الخطوات:

#### 1. أنشئ ملف `.ti`

أنشئ ملفاً جديداً في `static/terminfo/<اسم-الطرفية>.ti` باستخدام هذا التنسيق للعنوان:

```text
# -----------------------------------------------------------------------------
# Terminal: <اسم-الطرفية>
# Source:   <رابط إلى المصدر الرسمي أو التوثيق>
# License:  <مثل MIT, Public Domain, GPL-2.0>
# Notes:    <أي تعليمات خاصة أو تحذيرات>
# -----------------------------------------------------------------------------
```

مثال:

```text
# -----------------------------------------------------------------------------
# Terminal: ghostty
# Source:   https://github.com/ghostty-org/ghostty
# License:  MIT
# Notes:    محاكي طرفي Ghostty (2025+)
# -----------------------------------------------------------------------------
ghostty|محاكي طرفي Ghostty,
    ...
```

#### 2. تحقق من الملف محلياً

```bash
# التحقق من الصيغة
tic -x static/terminfo/terminal-name.ti

# تشغيل مجموعة التحقق الكاملة
contrib/run-all-checks.sh
```

#### 3. حدث الـ checksums

```bash
sha256sum static/terminfo/terminal-name.ti >> static/terminfo/checksums.txt
```

أو دع hook الـ pre-commit يقوم بذلك نيابة عنك (موصى به):

```bash
# إعداد لمرة واحدة
cp contrib/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

#### 4. افتح Pull Request

- أنشئ فرعاً: `git checkout -b add-terminal-name`
- قم بإرسال التغييرات (سيساعدك pre-commit hook)
- افتح PR مع وصف واضح

---

### ما الذي يجعل المساهمة جيدة؟

- يجب أن يترجم الإدخال **بشكل نظيف** باستخدام `tic -x`
- يفضل الإدخالات **الموثوقة** (من مشروع الطرفية نفسه)
- تضمين أكبر عدد ممكن من القدرات الحديثة (`XT`, `Tc`, `Su`, بروتوكول لوحة مفاتيح kitty، إلخ)
- توثيق المصدر بوضوح في العنوان

### مدونة قواعد السلوك

كن محترماً وبناءً. تتطور أجهزة المحاكاة الطرفية بسرعة — نحن جميعاً نحاول جعل حياة الطرفيات البعيدة أفضل للجميع.

لديك أسئلة؟ افتح issue أو أشر إلينا في الـ PR.
