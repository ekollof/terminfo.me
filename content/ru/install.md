## install.sh

Мы предоставляем хорошо прокомментированный и идемпотентный скрипт, который определяет вашу переменную `$TERM`, загружает соответствующий файл `.ti`, компилирует его с помощью `tic -x` и устанавливает в `~/.terminfo`.

### Быстрое использование

```bash
curl -fsSL https://terminfo.me/install.sh | sh
```

### С явным указанием имени терминала

```bash
curl -fsSL https://terminfo.me/install.sh | sh -s -- alacritty
```

### Проверка контрольных сумм

```bash
curl -fsSL https://terminfo.me/install.sh | sh -s -- --verify
```

### Что делает скрипт

1. **Самопроверка**: Загружает свежую копию себя и `install.json`, проверяет собственную SHA-256 и перезапускает проверенную копию (если не используется `--skip-self-check`).
2. Определяет вашу переменную окружения `$TERM`.
3. Сопоставляет её с файлом `.ti` из этой коллекции.
4. Загружает исходный файл по HTTPS.
5. При необходимости проверяет SHA-256 контрольную сумму файла terminfo.
6. Выполняет `tic -x -o ~/.terminfo <файл.ti>`.
7. Пропускает переустановку, если запись уже присутствует и актуальна.

### Самопроверка

Перед тем как делать что-либо ещё, скрипт выполняет самопроверку:

- Загружает свежую копию `install.sh` и `install.json` с сервера.
- Проверяет, что SHA-256 загруженного скрипта совпадает со значением, опубликованным в `install.json`.
- Если совпадает — перезапускает проверенную копию и продолжает работу.
- Если не совпадает (или загрузка не удалась) — скрипт аварийно завершается с ошибкой.

Это защищает вас, если файл `install.sh` на сервере (или в кэше) был подменён.

Вы можете отключить самопроверку с помощью `--skip-self-check` (не рекомендуется).

### Безопасность

- Скрипт **никогда** не запускает `tic` с правами `sudo` или повышенными привилегиями.
- Записывает данные только в `~/.terminfo` в вашем домашнем каталоге.
- Корректно завершается с понятными сообщениями об ошибках, если запись terminfo отсутствует.
- Вы можете в любой момент изучить скрипт перед тем, как передать его в `sh`.
