## Как внести свой вклад

Мы приветствуем качественные исходные файлы terminfo для терминалов, которых нет в системной базе ncurses, или для которых есть улучшенные/более полные определения.

**Примечание о языке:** Пожалуйста, пишите описания issues, pull requests и комментарии на английском. Это помогает сопровождающим эффективнее проверять вклад.

### Быстрый старт (рекомендуется)

Самый простой способ внести вклад — **сначала открыть issue**:

→ **[Отправить новый terminfo через GitHub Issue](https://github.com/ekollof/terminfo.me/issues/new?template=new-terminfo.yml)**

Это даёт нам возможность проверить файл и дать обратную связь до того, как вы откроете pull request.

---

### Ручной процесс (для опытных участников)

Если вы предпочитаете сразу открыть PR, следуйте этим шагам:

#### 1. Создайте файл `.ti`

Создайте новый файл в `static/terminfo/<имя-терминала>.ti` с таким заголовком:

```text
# -----------------------------------------------------------------------------
# Terminal: <имя-терминала>
# Source:   <URL на официальный источник или документацию>
# License:  <например, MIT, Public Domain, GPL-2.0>
# Notes:    <любые особые замечания или предупреждения>
# -----------------------------------------------------------------------------
```

Пример:

```text
# -----------------------------------------------------------------------------
# Terminal: ghostty
# Source:   https://github.com/ghostty-org/ghostty
# License:  MIT
# Notes:    Эмулятор терминала Ghostty (2025+)
# -----------------------------------------------------------------------------
ghostty|Ghostty terminal emulator,
    ...
```

#### 2. Проверьте файл локально

```bash
# Проверка синтаксиса
tic -x static/terminfo/ваш-терминал.ti

# Запуск полного набора проверок
contrib/run-all-checks.sh
```

#### 3. Обновите контрольные суммы

```bash
sha256sum static/terminfo/ваш-терминал.ti >> static/terminfo/checksums.txt
```

Или позвольте pre-commit hook сделать это за вас (рекомендуется):

```bash
# Одноразовая настройка
cp contrib/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

#### 4. Откройте Pull Request

- Создайте ветку: `git checkout -b add-ваш-терминал`
- Зафиксируйте изменения (pre-commit hook поможет)
- Откройте PR с чётким описанием

---

### Что делает хороший вклад?

- Запись **обязательно** должна чисто компилироваться с `tic -x`
- Предпочтительны записи, которые являются **авторитетными** (из самого проекта терминала)
- Включайте как можно больше современных возможностей (`XT`, `Tc`, `Su`, kitty keyboard protocol и т.д.)
- Чётко документируйте источник в заголовке

### Кодекс поведения

Будьте уважительны и конструктивны. Эмуляторы терминалов быстро развиваются — мы все стараемся сделать жизнь с удалёнными терминалами лучше для всех.

Вопросы? Откройте issue или упомяните нас в PR.
